# The sample CRM is now the Starter CRM

It moved to its own repository, so you can copy it with one click:
[github.com/Drop-Cowboy/starter-crm](https://github.com/Drop-Cowboy/starter-crm).

Click **Use this template** there, or run:

```bash
gh repo create my-crm --template Drop-Cowboy/starter-crm --private --clone
```
